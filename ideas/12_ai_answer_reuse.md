## 종합 기획

### 대상 사용자
- 한 과목의 개념 설명형 질문 사용자

### 문제 정의와 현재 근거
두 질문이 의미상 비슷해도 저장 답변이 새 질문의 조건·요구를 모두 답하지 못할 수 있다. 판정 기준은 질문 유사도가 아니라 기존 답변의 충분성이다.

### 최종 범위와 해결안
새 질문, 저장 질문, 저장 답변을 받아 수정 없이 재사용 가능한지 판정하는 NLP 실험과 간단한 시연. 특정 과목 하나로 제한하고 신규 답변 생성은 비교 비용 항목으로만 둔다.

### 기존 해결 방식과 경쟁
- 완전 일치 기준선
- 임베딩 유사도 검색
- 검색 후 질문 조건·답변 충분성 재판별

### 시장·문제 검증 계획
1. 정확성이 확인된 질문·답변 80~100개, 새 질문 300~400개를 구성한다. 표현 변형·추가 조건·숫자/부정/대상 함정·풀에 없는 질문을 포함한다.
2. 두 사람이 재사용 가능성을 독립 판정하고 불일치를 해결한다. 원본 답변 기준으로 개발·시험을 분리하고 임계값은 개발에서 고정한다.
3. 재사용 정확도, 재사용률, 잘못된 답 제공률, 가능한 질문 회수율, 처리 시간·비용을 보고하고 정확도-재사용률 곡선을 그린다.
4. 5주: 기준·범위, 질문·라벨, 기준선, 재판별 평가, 보고·시연. 실제 작성 질문은 실사용 추정용 별도 시험 묶음으로 둔다.

### 위험과 중단 조건
- 가상 생성 질문으로 실제 사용자 재사용률을 추정하지 않는다.
- 낮은 성능도 실패 질문 유형 분석으로 결과화한다.

### 남은 결정
- 우선 과목을 정하고 답변의 정확성 검수 출처를 확보한다.
- 실제 독립 질문 표본을 수집할 수 있는가?

## 문제 정의
저장된 질문이 “Transformer의 attention을 설명해줘”이고 새 질문이 “Attention의 시간복잡도를 행렬 크기와 함께 설명해줘”라면 주제는 비슷합니다. 하지만 기존 답변이 시간복잡도와 행렬 크기를 설명하지 않는다면 재사용할 수 없습니다.
따라서 이 프로젝트의 정답은 **두 질문이 비슷한가**가 아니라 **기존 답변이 새 질문에 충분한가**입니다.
## 데이터 계획
1. 운영체제, 머신러닝 입문 등 한 과목을 정합니다.
2. 정확성을 확인한 기존 질문·답변을 80~100개 준비합니다.
3. 새 질문 300~400개를 만듭니다. 표현만 다른 질문, 조건이 추가된 질문, 숫자·부정·대상을 바꾼 함정 질문, 답변 풀에 없는 질문을 섞습니다.
4. 가능하면 학생들이 독립적으로 작성한 실제 질문을 별도 시험 묶음으로 수집합니다.
5. 두 사람이 각 `(새 질문, 기존 답변)` 쌍의 재사용 가능 여부를 독립적으로 판정하고, 불일치를 해결합니다.
직접 만든 변형 질문은 모델의 약점 시험에 적합합니다. **실제 사용자의 재사용률**을 추정할 때는 독립적으로 작성된 질문 묶음의 결과를 별도로 보고해야 합니다.

예를 들어 질문 100개 중 30개에 기존 답을 제공했고 27개가 맞았다면 재사용 정확도는 90%, 재사용률은 30%, 잘못된 답 제공률은 3%입니다. 이 수치는 **가상의 계산 예시**입니다.
점수 기준을 여러 값으로 바꿔 **재사용 정확도–재사용률 그래프**를 그립니다. 기준은 개발 데이터에서 정하고 시험 데이터에서는 바꾸지 않습니다. 동일한 원본 답변에서 만든 질문들이 개발·시험 양쪽에 섞이지 않도록 나눕니다. 처리 시간과 검색·재판별·신규 답변 생성 비용도 함께 기록합니다.

## 팀 역할 예시
- **데이터·평가:** 질문 구성, 주석 지침, 사람 판정 관리
- **모델·실험:** 기준선과 개선 방법 구현, 지표 계산
- **분석·발표:** 오류 사례 분석, 시각화, 보고서·발표
## 최종 발표에서 보여줄 것
1. 방법별 성능 표
2. 재사용 정확도–재사용률 그래프
3. 잘못 재사용한 대표 사례 5~10개와 원인
4. 독립 질문에서 측정한 재사용률과 실험의 한계
결과가 낮게 나와도 **어떤 질문에서 재사용이 실패하는지**를 밝혀내면 의미 있는 NLP 프로젝트가 됩니다.
