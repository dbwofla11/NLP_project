## 한 줄 정의

예비창업패키지·교내 창업경진대회를 준비하는 기술기반 예비창업 1~3인 팀이 여러 아이디어를 증거와 반증으로 비교하고, 승인된 주장만 사업계획서 문단에 연결해 작성·수정·재검증하는 워크스페이스다.

## 문제

예비창업자는 시장조사, 경쟁사 탐색, 포지셔닝 설정, 사업계획서 작성을 분리된 도구에서 반복한다. 아이디어별로 같은 조사를 되풀이하고, 검증 근거와 문서 문장이 분리돼 수정 때마다 근거를 다시 확인해야 한다. 출처 없는 문장이나 최신성이 사라진 근거가 남을 위험이 있다.

## 제안 솔루션과 MVP

Source Scout, 시장·경쟁 분석가, Skeptic, Evidence Judge, Writer 역할로 근거 수집·반증 탐색·검토·초안 작성을 나눈다. 사람 승인 전에는 최종 문장으로 확정하지 않으며, 후보 비교표·근거 카드·반증 목록·사업계획서 초안을 제공한다. 초기 MCP·DB 연결은 허용 목록의 읽기 전용 데이터로 제한한다.

## 검증 과제

DocsHunt와의 차별점이 실제 시간을 줄이고 지불 의사를 만드는지 사용자 인터뷰 15~20건과 5팀 파일럿으로 확인한다. 현재 작업 흐름, 시간·도구 비용, 문서 수정 빈도를 측정한다.

# 문제제기
## 1. 시장조사·사업계획서 준비에 필요한 리서치와 도구 부담
- 예비창업자는 시장 규모, 고객 문제, 경쟁사, 지원사업 요건을 각각 탐색해야 함.
- 탐색 결과를 사업계획서 문장으로 옮기는 과정이 별도 작업으로 발생함.
- 유료 리서치·문서작성 도구 사용 시 비용 부담이 지속됨.
- 중소벤처기업부 2023년 조사에서 창업 준비 중요도는 시장조사 79.1점, 사업계획서 65.8점으로 확인됨.
- 예비창업 개발자 집단의 실제 도구 비용·이용률은 별도 설문으로 확인 필요함.
## 2. 아이디어별 시장성·포지셔닝 검증의 반복 부담
- 여러 아이디어를 비교할 때마다 고객 문제, 대체재, 경쟁사, 진입 근거를 다시 조사해야 함.
- 검증 기준이 고정되지 않으면 아이디어 간 비교 결과의 일관성이 낮아짐.
- 중소벤처기업부 2022년 조사에서 실제 창업 준비 활동으로 시장조사 64.5%, 사업계획서 작성 41.0%가 확인됨.
- 해당 수치는 예비 기술창업 개발자만을 뜻하지 않으므로 보조 근거로 활용함.
## 3. 검증 근거와 사업계획서 수정의 분리
- 시장 근거와 반증이 문서 초안과 분리되어 저장됨.
- 문장 수정 후 근거의 최신성·정합성을 다시 확인해야 함.
- 출처 없는 문장이 남거나, 근거가 바뀌어도 기존 문장이 유지될 위험이 발생함.
- 주장·출처·사업계획서 문단을 연결하는 관리 기능이 필요함.

# 솔루션
## 검증 전용 서브에이전트 하네스
- Source Scout: 공공통계·공식 공고·기업 자료·신뢰 가능한 웹 출처 수집함.
- Market/Competitor Analyst: 시장 구조·고객 세그먼트·경쟁사·대체재 비교함.
- Skeptic: 과장된 시장 가정, 경쟁 누락, 반증 사례를 탐색함.
- Evidence Judge: 출처 신뢰도·최신성·주장 적합도를 점검함.
- Writer: 사람 승인된 주장만 사업계획서 항목별 초안으로 변환함.

# 1. 문제 상황의 구체성 검증
## 이미 구체화된 요소
- **고객:** 예비창업패키지·교내 창업경진대회를 준비하는 기술기반 예비창업 1~3인 팀.
- **상황:** 시장 규모·고객 문제·경쟁사·지원 요건을 찾아, 이를 공고 양식의 사업계획서 문장으로 옮기고 수정하는 과정.
- **손실:** 조사 결과와 문서가 분리되어 재확인 작업, 출처 누락, 오래된 근거가 남는 위험이 생김.
- **기존 대안:** DocsHunt는 공고 선택, 사업계획서 생성, 근거자료 탐색, AI 수정, HWPX 내보내기를 제공한다. 따라서 단순 ‘AI 사업계획서 작성’은 이미 시장에 존재하는 해결 방식이다.[DocsHunt 기능·요금](https://docshunt.ai/pricing)
## 부족한 구체성
- ‘기술기반 예비팀’ 안에서도 대학생·예비창업패키지 신청자·연구실 스핀오프 중 **누가** 가장 강한 문제를 겪는지 분리되지 않았다.
- 공고 1건당 조사·작성·수정에 드는 시간, 공동작성 중 충돌 횟수, 출처 갱신 때문에 다시 쓰는 문단 수가 없다.
- 오류의 결과가 ‘탈락 위험’, ‘멘토 피드백 반복’, ‘팀 의사결정 지연’ 중 무엇인지와 비용이 측정되지 않았다.
- DocsHunt가 근거 탐색과 편집을 이미 제공하므로, 주장-출처-문단 추적과 반증 탐색이 실제로 해결하지 못하는 빈틈인지 아직 입증되지 않았다.
## 판정 이유
문제의 **대상·과업·불편·기존 대안**은 드러나 있어 인터뷰 가능한 가설 수준이다. 하지만 강도·빈도·비용이 수치화되지 않아, 당장 제품 요구사항을 확정할 수준의 구체성에는 이르지 못했다.
# 2. 반복 발생성의 시장 근거
- 원 아이디어에 인용된 중소벤처기업부 2022년 창업기업실태조사는 창업 준비 활동으로 시장조사 64.5%, 사업계획서 작성 41.0%를 제시한다. 이는 두 과업이 창업 준비 과정에서 실제로 발생한다는 보조 근거다.[2022년 창업기업실태조사](https://www.mss.go.kr/cmm/fms/FileDown.do?atchFileId=FILE_000000001008122&fileSn=1)
- 같은 페이지에 인용된 2023년 조사에서는 창업 준비 중요도가 시장조사 79.1점, 사업계획서 65.8점으로 제시된다. 반복 사용량을 직접 증명하지는 않지만, 두 과업이 주변 업무가 아닌 핵심 준비 활동이라는 점을 뒷받침한다.[2023년 창업기업실태조사](https://www.mss.go.kr/cmm/fms/FileDown.do?atchFileId=FILE_000000001008674&fileSn=1)
- 2025년 중소벤처기업부 예비창업패키지 공고는 서류평가에서 사업계획서를 평가하고 사업계획서 유사·중복성도 검토한다고 명시한다. 공고 지원이라는 특정 시장 맥락에서 문서 작성·검토가 한 번의 일회성 메모가 아니라 심사 단계의 필수 산출물임을 보여 준다.[예비창업패키지 공고](https://tv.mss.go.kr/common/board/Download.do?bcIdx=1056993&cbIdx=310&streFileNm=58f40c84-3d84-4eba-b71a-c2def45f30c9.pdf)
- DocsHunt가 지원사업 추천, 공고별 양식, 재사용 가능한 AI 메모리, 월 구독형 기능을 제공하는 점은 반복적인 공고 준비·문서 수정 수요가 있다는 **공급자 측 신호**다. 단, 해당 서비스의 이용자 수·효과 주장은 독립 검증 자료가 아니므로 수요 규모의 근거로 사용하지 않는다.[DocsHunt 서비스 소개](https://docshunt.ai/)
## 반복성 판정의 한계
시장조사·계획서 작성의 발생은 확인되지만, 본 아이디어의 핵심인 ‘복수 아이디어 비교 → 반증 탐색 → 문단 수정 뒤 재검증’이 같은 팀에서 몇 회 반복되는지는 공개 통계로 확인되지 않았다. 따라서 반복성은 **업무 흐름 수준에서는 부분 충족**, 제품 기능 단위에서는 미확정으로 판정한다.
# 3. 반드시 보완할 현장 검증
1. 목표 고객 15~20명에게 최근 공고 준비 1건을 기준으로 조사·초안·수정 시간, 사용 도구, 출처 재확인 횟수를 인터뷰한다.
2. 5팀에게 실제 공고 양식으로 후보 2개 이상을 비교하게 하고, 일반 문서/DocsHunt류 도구 대비 근거 찾기·수정 시간을 측정한다.
3. 성공 기준을 사전에 고정한다: 팀당 재검증이 필요한 문단이 3개 이상이고, 주장-출처-문단 연결 기능으로 총 준비 시간이 최소 20% 줄어들며, 5팀 중 3팀 이상이 다음 공고에도 사용 의사를 보이는지 확인한다.
4. 이 기준을 충족하지 못하면 ‘근거 추적 워크스페이스’가 독립 제품이 아니라 기존 사업계획서 도구의 보조 기능일 가능성을 검토한다.
