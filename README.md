# NLP_project
자연어처리 수업 프로젝트 

## 현재 프로젝트 상태
현재 아이디어를 구상하고 프로젝트 주제를 정하는 단계입니다. 아래 아이디어들은 주제 선정을 위한 후보입니다.

## 수업 최종 목표
생활 속에서 반복되는 문제를 찾고, 자연어 처리 기법으로 해결 가능한 형태로 정의하고 구현합니다.

## 수업 내용
- 일상 속 문제를 관찰하고 사용자·상황·피해를 구체화합니다.
- 문제에 맞는 자연어 처리 기법을 선택해 해결 방안을 구현하고 검증합니다.
